自チームに対して、エンジンが「能力の高い選手を要職に自動配置」してはいけない。
配置そのものが隠しパラメータのリークになる。

具体例（どちらも 2026-05-19 に修正、[[project_hidden_parameters]] 違反）:
- 救援ロール（抑え/セットアッパー等）を生成時に能力順で自動割り当てしていた
  （最強投手＝抑え）。→ 自チームの救援は開幕時すべて「中継ぎ」、ユーザーが
  試合結果から推測して `setReliefRole` で指定。
- 作戦画面の初期打順を能力で自動算出していた（4番＝最強長打…＝能力ランキング）。
  → 自チームは背番号順の中立打順で提示し、ユーザーが観察して並べ替える
  （`LineupPlanner.neutralOrder`）。守備適性ベースの配置は可視情報なので残す。
どちらも CPU は能力ベースのまま（対戦相手の偵察は推測ゲームの一部）。

**Why:** パラメータ非表示の本作では「結果を観察して能力を推測する」のが遊びの
中心。エンジンが能力ベースで役割・打順・起用を決めて見せると、その出力が
能力の答え合わせになってしまう。

**How to apply:** 自チームの編成補助でエンジンが何かを「能力順で」自動決定する
機能を足すときは、それが UI に出る＝能力ヒントになると考える。中立な初期状態
（全員同じ役割など）から始め、ユーザーが推測で決める。CPU 5 球団は対象外
（対戦相手の偵察は推測ゲームの一部で、リークではない）。
