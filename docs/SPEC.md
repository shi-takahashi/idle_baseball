# 放置系プロ野球GMになろう！ - 仕様書

## コンセプト

架空のプロ野球チームのオーナー兼GMとして、チームを運営する放置系シミュレーションゲーム。
ベストプレイプロ野球のエッセンスを残しつつ、アニメーションを省略し、放置系の要素（時間による変化）を加えた設計。

### 中心となる遊び方: パラメータは「見せない」（2026-05-17 方針変更）

**選手の能力パラメータは、基本（無料プレイ）では非表示にする。**
エンドユーザーは試合結果を観察し、「この選手はホームランをよく打つから4番にしよう」
「この投手は終盤に崩れやすいから早めに代えよう」というように、**結果から能力を推測して
采配を決める**。

**なぜパラメータを隠すのか:**
- パラメータが見えると、「数値に応じた打順」を組んだ時点で最適解が確定し、放置系という
  性質も相まって**他にやることがなくなり、すぐ飽きる**
- 現実のプロ野球に「パラメータ」という数値は存在しない。監督・GM は練習の動きや試合結果
  から采配を決めている。パラメータを隠す方が**現実に近く、かつ他の野球ゲームとの差別化**
  になる
- 「観察して推測する」こと自体を継続的な遊びの中心に据える

※ パラメータ自体は内部のシミュレーションモデルとして存在し続ける（§2）。
  「ユーザーに数値として見せるかどうか」だけが変わる。パラメータの表示・編集は
  課金で解放する（§5）。

### 設計の柱（推測ゲームとして成立させる条件）

パラメータ非表示を中心に据える以上、「結果を観察して能力を推測する」ループが
ちゃんと回ることがゲーム成立の前提になる。以下の 4 点を、今後のバランス調整・
機能追加すべての判断基準とする。

**① パラメータと結果が、ある程度直結していること**

能力値が結果に明確に効かないと、そもそも推測の手がかりが無くなる。
（例: 2026-05-17 に長打力→本塁打を非線形カーブ化し、長打力9 ≒ 40本 /
長打力4 ≒ 1桁 まで差を広げた。CHANGELOG 参照）

**② リアリティと「推測可能性」の 2 軸で調整する**

従来の調整軸は「NPB 実測値に合わせる」だけだったが、ここに
「結果から能力を推測できるか」を加える。判断尺度は **シーズン成績の S/N比**:

- 1シーズンの成績にはノイズ（試合ごとの揺れ）がある。例: 150試合の本塁打の
  標準偏差は ~6本程度
- **極端な能力差ははっきり分かるべき**（長打力9と5は ~4〜5σ 離れ、1シーズンで
  「長距離砲だ」と分かる）
- **隣接する能力差は1シーズンでは曖昧でよい**（長打力5と6は ~1σ）。
  隣同士まで即見抜けたら簡単すぎる
- ランダム性が強すぎる → 推測不能。弱すぎる → 簡単に解けて飽きる。
  この中間（極端は分かる/隣接は曖昧）を狙う

**③ すべての能力が、観測できる成績に footprint を持つこと**

推測ゲームでは「どの成績を見ても影響が表れない能力」は、ユーザーから見て
存在しないのと同じ（あるいは正体不明の運要素になる）。各能力について
「何を見れば推測できるか」を確保する。現状の整理:

| 能力 | 観測手段 | 推測しやすさ |
|------|----------|--------------|
| 長打力 | 本塁打・長打率 | ◎ |
| ミート | 打率 | ○ |
| 選球眼 | 四球 | ○ |
| 走力 | 盗塁・三塁打・内野安打 | ○ |
| 守備力・肩 | 失策・被打率 | △（チーム成績に埋もれやすい） |

△ の能力は「観測可能にする」「影響を割り切る」のどちらかを今後決める。
※ 旧「リード」「スタミナ」は推測可能な役割を持たなかったため、能力パラメータ
  としては廃止した（2026-05-17。リードは捕手の守備力に統合、スタミナは全投手
  共通の疲労カーブ＋中4日ルールに置換）。

**④ 一度定まった評価が、固定でなく動き続けること**

成長・衰えにより、「この選手は4番」という結論が永久には正しくなくなる。
毎シーズン結果を測り直す必要があり、推測ゲームが**完了しない**＝飽きにくい。

- 衰え/成長は、シーズン間のノイズと区別できる強さで出す（②と同じ S/N比 の話）
- **年齢は非表示にしない。** 「35歳だし衰えてきたか」と、年齢を手がかりに
  結果の変化を解釈できる。年齢は推測の足場
- 若手の成長は出場機会がないと観測できない → 若手を試す動機づけが要る
- **成長タイプ（早熟/普通/晩成）の導入**がこの柱に直結する（晩成型＝
  「期待してなかった若手が伸びた」の正体）。全員同じカーブだと成長が
  予測可能になり推測ゲームとして浅くなる。現状未実装（§決定事項）

## 1. ゲームの基本仕様

### 1.1 試合の進行

| 項目 | 仕様 |
|------|------|
| 試合タイミング | 毎日決まった時間に自動で1試合実行 |
| 結果確認 | 設定時刻以降にユーザーが結果を確認 |
| 表示形式 | スコアボード形式（新聞風） |

**試合結果の時刻設定・通知（アイデア、未実装）:**
- 試合結果が出る時刻を**設定画面でユーザーが変更可能**にする
- 設定時刻になったら**ローカルプッシュ通知**を送る（「本日の試合結果が出ました」等）。
  サーバー不要のローカル通知で実現する

### 1.2 リーグ構成

| 項目 | 仕様 |
|------|------|
| チーム数 | 1リーグ6チーム |
| シーズン試合数 | **30 / 90 / 150 試合から選択可能**。デフォルト 30。翌シーズン開始時は前シーズンと同じ値が初期選択。150 試合は NPB 143 試合（2 リーグ + 交流戦込み）を 1 リーグでカバーする想定 |
| シーズン期間 | 試合数 × 1 日（30 試合なら約 30 日） |

### 1.3 試合結果の表示

- **スコアボード**: 各イニングの得点を新聞形式で表示
- **個人成績**: 打撃成績、投手成績を表示
- **詳細表示**: 各イニングの表/裏を選択すると、打席ごとの対戦詳細を確認可能
  - どの投手 vs どの打者
  - 結果（ヒット、三振、ホームラン等）

## 2. 選手パラメータ

### 2.0 表示方針（2026-05-17）

以下のパラメータは**内部のシミュレーションモデル**であり、基本（無料プレイ）では
ユーザーに数値として表示しない（§コンセプト参照）。表示・編集は課金で解放する（§5）。
ゲームエンジン・生成・成長ロジックは従来どおりパラメータを使い続ける。

**ただし、構造的・カテゴリ的な属性は無料プレイでも表示する。** 1〜10 の細かい
能力値は隠すが、現実の GM が当然知っている属性まで隠すと采配（特にスタメン
編成）が成立しない。線引きの原則: **「能力の巧拙を表す 1〜10 の数値は隠す／
現実の GM が当然知っている構造的属性は見せる」**。

| 属性 | 扱い |
|------|------|
| ミート / 長打力 / 選球眼 / 走力 / 守備力の数値 / 球速 / 制球 / 各球種… | 隠す（結果から推測） |
| 守備適性（守れるポジション） | **見せる** |
| 利き腕・打席（右 / 左 / 両） | **見せる** |
| 年齢 | **見せる**（衰え/成長の推測の足場。§設計の柱④） |

- **守備適性**: 守れないポジションに置くと失策が激増する（強制配置ペナルティ ×3）。
  どこを守れるか分からないとスタメンが組めず、外すと「楽しい推測」ではなく理不尽な
  罠になるため、表示は必須。ただし守備力の**数値**（1〜10）は他能力と同様に非表示と
  し、同じ守備位置内の巧拙は試合結果（失策・守備範囲）から推測させる。
- **投手のロール（先発 / 中継ぎ / セットアッパー / 抑え）**: これは「見せる/隠す」では
  なく **ユーザー自身が設定する**（§3）。「この投手は球が速そうだから抑えに」「抑えへ
  繋ぐセットアッパーはこの投手に」と、試合結果から能力を推測して起用を決めるのも采配の
  楽しみの一部。自動の初期割り当ては置くが、ユーザーが上書きできるようにする。

### 2.1 評価方式

- 10段階評価（1〜10）。**自動生成は 1〜9**（10 は手動編集でのみ到達する特別値）
- 年齢と成長タイプにより毎シーズン能力が変動

### 2.2 野手パラメータ（実装済み）

| パラメータ | 説明 |
|-----------|------|
| ミート | バットにボールを当てる能力 |
| 長打力 | 長打を打つ能力 |
| 走力 | 走る速さ・盗塁・進塁判定 |
| 選球眼 | 四球の取りやすさ |
| 肩力 | 送球の強さ（ポジション別効果: 捕→盗塁阻止 / 外→タッチアップ阻止 / 内→内野安打阻止） |
| 守備力 | ポジションごとの守備力（0〜10、0=守れない）。捕手の守備力はリード（配球）も兼ね、被打率にわずかに効く |

### 2.3 投手パラメータ（実装済み）

| パラメータ | 説明 |
|-----------|------|
| 球速 | ストレートの速さ（km/h） |
| 制球 | コントロールの良さ |
| 伸び | キレ・ノビ（球速とは独立して被打率・空振りに影響）。内部フィールド名は `fastball` |
| スライダー / カーブ / スプリット / チェンジアップ / シュート / カットボール / シンカー | 各変化球のパラメータ（1〜10、null=投げられない）。計7変化球。シュート・シンカーは空振りは取れないがゴロを打たせる球で、走者ありで併殺を奪いやすい |

※ スタミナは能力パラメータとして廃止（2026-05-17）。試合内の疲労は全投手共通の
  カーブ（80球で出始め140球で完全）で表現し、先発は中4日空けないと登板できない
  ルールにした。リードと同じく「観測できず役割の無い能力値は持たない」方針。

### 2.4 共通パラメータ

| パラメータ | 説明 |
|-----------|------|
| 利き腕 / 打席 | right / left / both（両打ち） |
| 年齢 | 現在の年齢（成長機能は将来実装） |
| 成長タイプ | 早熟/普通/晩成（将来実装） |
| ポジション | 野手: C/1B/2B/3B/SS/LF/CF/RF、投手: SP/RP/CP |
| 投手ロール | 先発/抑え/セットアッパー/中継ぎ/ワンポイント/ロング/敗戦処理。自チームは全投手にユーザーが指定（先発6→「先発」/救援12→「中継ぎ」が初期値）。先発/中継ぎの区分は固定でなく、先発・ベンチ入りとも全18投手から自由に選ぶ。先発ロールの投手はリリーフ最低優先（他の救援が出尽くした時のみ登板） |

### 2.5 隠しパラメータ（UIに表示しない）

| パラメータ | 説明 |
|-----------|------|
| 投手コンディション | 試合ごとに ±2 のランダム補正（球速・制球・各球種に作用） |
| 野手コンディション | -1/0/+1 の3状態を Markov 遷移で複数日持続。打者の能力に一律加算 |
| 直近成績（RecentForm） | 直近30打席のローリング窓 OPS。打順決定・スタメン入れ替え判定に使用 |
| ポテンシャル上限 | 各能力ごとに生成時に確定する成長上限値。加齢成長時のクランプに使う。`初期 + 2.0 + rookieBonus + gauss(sd=1)` で算出、最大 9（10 のみ initial=10 で維持）。新人タイプ別 bonus: 高卒 +1.5 / 大卒 0 / 社会人 -0.5。球速 (km/h) は別係数で自然上限 158 km/h |

## 3. ユーザー操作（シーズン中）

放置系だが、以下の指示が可能：

| 操作 | 説明 |
|------|------|
| スタメン設定 | 翌日の先発メンバーを指定 |
| 打順設定 | 打順を変更 |
| 先発投手指定 | 翌日の先発投手を**全18投手から**指定（先発/中継ぎの区分は固定でない） |
| ベンチ入り指定 | 当日ベンチ入りする控え野手9・救援8を指定。救援8は**全18投手から**選ぶ（先発させたい投手はベンチ入りさせず休ませる） |
| 投手ロール設定 | 各投手のロール（先発 / 抑え / セットアッパー / 中継ぎ / ワンポイント / ロング / 敗戦処理）をユーザーが設定。試合結果から能力を推測し「この投手は球が速そうだから抑え」と起用を決める（§2.0）。開幕時は中立な初期ロール（先発6→先発 / 救援12→中継ぎ）。先発ロールはリリーフ最低優先 |

## 4. オフシーズン（ストーブリーグ）

シーズン終了後に実行可能：

| イベント | 説明 |
|---------|------|
| ドラフト会議 | 新人選手を獲得 |
| トレード | 他チームと選手交換 |
| 外国人獲得 | 海外からの助っ人を獲得 |
| 自由契約 | 選手を放出 |
| 契約更新 | 選手との契約 |

### 4.1 外国人選手枠（助っ人）（2026-05-21 導入 / 2026-05-22 拡張）

各チームに**先発ローテ 2 名 + ベンチ 2 名 = 計 4 名**の外国人選手を配置する
（NPB 通常運用に合わせる）。リーグ全体で 24 名。
野手枠 22 / 投手枠 18 は固定で、内訳として「外国人投手 2 + 日本人投手 16」
「外国人野手 2 + 日本人野手 20」。

**名前生成（2026-05-22）:**
- NPB の登録名慣習に倣い **苗字単独**（例: ベラスケス、スミス、ローズ）
- 同チームに同苗字が居る場合のみ除外して抽選 → チーム内では衝突しない
- 別チーム同士の同苗字（フェニックスのローズ vs ブリザーズのローズ）は許容
- 苗字リストは 200 種（ヒスパニック 100 + 英語圏 100）。1 チーム外国人 4 名で
  35〜40 年は重複感が出にくいレンジ

**生成パラメータ（野手）:**
- 能力分布は中央集中だが日本人より若干バラつく（sd 1.6 / 日本人 1.5）
- mean: ミート 4.5 / 長打 5.5 / 走力 4.5 / 選球眼 5.0 / 肩 5.0
  → 長打型のパワーヒッター、その代わりミート・走力で日本人より一歩劣る、
    トータルでは互角（合計 24.3 / 日本人 24.7）
- 守備位置: 一塁 30% / 外野 40% / 三塁 15% / 二塁 10% / 遊撃 5%
  **捕手はなし**（言語コミュニケーションの問題で NPB 外国人捕手は存在しないため）
- 守備位置 1 つだけ（ユーティリティ性は低い）
- 年齢: mean 27 / sd 3.5 / 22-35（新規獲得は中堅 27〜30 中心。35 歳以上の
  新規獲得は実例が稀。チーム所属で加齢して 35+ になるのは別問題）

**生成パラメータ（投手）:**
- 球速 +3 km/h（mean 150）、制球 -1（mean 4.0）、伸び・変化球は日本人と同等
- 当たり外れの幅（sd 1.6）も野手と同じ
- 左投手比率 30% → 40%（NPB 外国人左腕の人気）

**強制離脱と手動入替 UI（2026-05-22 実装）:**
- シーズン終了時、各外国人について独立に **1/5 の確率で強制離脱**
- キャリア平均 5 年で離脱する目安。優秀な選手でも例外なく確率は一律
- ただし **1 シーズンで離脱するのは最大 2 名まで**（自チーム・CPU 共通）。
  独立判定で 3 人以上の同時離脱が出た場合は乱数で 2 名に丸める（先頭優遇
  を避けるためシャッフル後に切り詰め）。アラート領域の圧迫と急激な選手
  入替を抑える目的
- **自動補充は撤回**。オフシーズン編成画面の「野手」「投手」タブそれぞれに、
  該当タイプの現役外国人 + 新候補 3 名（投手 3 + 野手 3 = 計 6）を表示
- ユーザーは強制離脱を確認し、任意で他の選手を「契約解除」もできる。空いた
  枠ぶんを候補から獲得して埋める。獲得しないと「次シーズン開始」が押せない
- **整合性**: 投手枠・野手枠ごとに「現状 − 離脱 − カット + 獲得 = 想定枠 2」
  を満たす必要がある。ペアできない獲得（離脱より獲得が多い）はチームに新規
  追加で空席を埋める
- CPU 球団は引き続き「強制離脱 → 即自動補充」（手動 UI は持たない）
- 日本人引退枠とは完全に分離（タブも分かれ、外国人を日本人新人で置き換える
  操作は UI 上不可能）

**逸材の出現頻度（リーグ 24 人中）:**
- 長打 9（50本級）: 0.8 人（数年に1人の逸材）
- 長打 8（タイトル級）: 2 人
- 長打 7（強打者）: 4 人
- ミート・走力・肩・選眼の 9: いずれも 1 人未満（中央集中で現実離れした能力は稀）

**パラメータ非表示の方針（§コンセプト）との整合:**
- 新外国人候補は能力非表示、守備位置・年齢・名前のみが事前情報
- 獲得後は試合結果で「当たりか外れか」を推測する賭け体験
- 新人野手・投手で出ている A/B/C のスカウト評価は外国人候補では出さない
  （外国人は「事前情報がより少ない、よりギャンブル性が高い枠」として差別化）

**次フェーズの調整候補:**
- 外国人能力の底上げ: 現状の生成パラメータだと「活躍しない助っ人」が多そう。
  NPB 助っ人らしい「打てるが守れない」「球速はあるが制球難」のような尖りを
  強める方向で再調整
- 強制離脱時のシーズン中通知（オフシーズン編成画面の外国人タブ内には
  `[離脱]` バッジで表示されるが、シーズン中の通知は未実装）

## 5. 収益化モデル（2026-05-17 改訂）

### 5.0 収益設計の考え方

- **無料版がプロダクトの基本**。それ単体で完結した「推理ゲーム」として面白いことを
  最優先する。多くの野球ゲームはパラメータが最初から見えるため、非表示の無料版は
  珍しい形になる。メガヒットは狙わず、「こんな遊び方があったのか」と**一部のユーザーに
  刺さるニッチ**を狙う
- **収益の基本線は広告**。試合結果を見るタイミングのインタースティシャル広告だけでも
  一定の収益が立つ前提で設計する。課金は必須ではない
- 課金は「**不便の解消**」ではなく「**別の遊び方の追加**」（パラメータ表示＝攻略志向 /
  編集＝現実シミュレーター）。**無料版をわざと不便にして課金に誘導する設計はしない。**
  無料の推理ゲームがストレスで成り立っていると、課金が「モヤモヤを金で解消する」体験に
  なり不満・解約を招く。課金は前向きな「もう一面を見たい」で発生させる
- 実装の優先順位: **まず無料の推理ゲームを面白くする → 課金ゲートはその後**

### 5.1 基本プレイ（無料）

- 選手パラメータは**非表示**。試合結果から能力を推測して采配する（§コンセプト）
- 試合進行は**現実時間に同期**。1日1試合だけ進む（放置して翌日結果を見る）
- 広告あり（バナー / リワード動画）

### 5.2 課金で解放する機能（月額サブスクリプション）

「パラメータの表示 → 編集」を**2段構え**にしているのが核。課金で
「現実では不可能な遊び方」へ段階的に踏み込める。

| 課金機能 | 内容 | 想定価格 |
|---------|------|---------|
| パラメータ表示 | 選手の能力値を数値で閲覧できる | +月額100円 |
| パラメータ編集 | 能力値の閲覧 **＋** 自由な編集（表示課金を内包） | さらに+月額100円（計200円） |
| 時間スキップ | 現実時間を待たず複数試合を連続消化 | 未定 |
| 広告削除 | 広告を非表示 | 未定 |

**パラメータ表示課金（1段目）の狙い:**
- 「数値を見て最適な打順・起用を組みたい」という攻略志向の層向け
- 推測プレイに飽きた / 答え合わせをしたいユーザーの受け皿

**パラメータ編集課金（2段目）の狙い:**
- 能力値を自由に書き換えられる。**現実のプロ野球選手のデータに置き換えれば、
  現実のプロ野球シミュレーションが成立する**
- 公式データではない（ユーザー自身が入力する）ため版権問題を回避
- 「自分だけのプロ野球シミュレーション」という、現実にはできない遊び方を提供

**時間スキップ:** 無料は現実時間同期で1日1試合。課金で放置の待ち時間を短縮できる。

### 5.3 課金基盤

- **RevenueCat** を使用
- 自前サーバー不要
- Google Play / App Storeの課金をRevenueCatが代行
- 月間収益$2,500以下は無料で利用可能

### 5.4 実装上の留意点（将来対応）

- 現状の選手能力詳細画面（`player_detail_screen`）・編集画面（`player_edit_screen`）は
  **誰でも閲覧・編集できる**。課金状態に応じたゲート（非課金は非表示）を将来実装する
- パラメータ非表示時の代替 UI（試合結果ベースの選手評価の見せ方）を別途検討する

- **年度別成績**: 各選手の「○年目: 打率.290 30本」を年ごとに並べて表示。

- データ量の方針:
  - **現役選手**: 年度別履歴をフルに保持（衰え/成長の推理に必須）

  - 1球ごとのログは従来どおり最新試合のみ保持（年度別成績とは別レイヤー）

## 実装済みのゲームメカニクス（抜粋）

- 1球ごとのシミュレーション（球種選択・球速・制球・疲労・コンディション）
- 配球バリエーション（同球種連続ペナルティで連続 4 球以上は実質発生しない）
- 球種 8 種類（ストレート + 変化球7種）。持ち球は各変化球を独立保有確率（NPB 投手割合準拠）で抽選し、最低 2 変化球保証（合計3種類）・最大5変化球
- インプレー結果（ゴロ/フライ/ライナー × 9方向 × 守備力）。打球タイプは球種依存（ゴロ率 ストレート 43%〜シンカー 67.5%）。リーグ平均でゴロ ~50% / フライ ~38% / ライナー ~12%。シュート・シンカーはゴロ→併殺を奪いやすい
- 走塁（盗塁・追加進塁・タッチアップ・併殺・内野安打）。内野安打では走者の追加進塁は発生しない（1塁→2塁・2塁→3塁・3塁→生還で固定）
- 死球（HBP）: 投球の独立試行で発生（制球 5 で 0.35%/球、制球-1 ごとに +0.06pt）。1 team-game あたり約 0.4 件で NPB 水準。打数に含めず、OBP の分子・分母に算入
- バッテリーエラー（WP / PB）とフィールディングエラー
- プラトーン補正（左vs左の打者不利）と引っ張り傾向
- 投手交代（先発 100 球目安・抑え/セットアッパー等のロール起用）
- 代打・代走・守備配置の自動再編。代打は「打撃能力（meet+power）と打順」で判定し、クリーンアップ（3,4,5番）は除外。投手は通常打撃能力が低いため自然に代打が成立し、代打成立時は次の守備で強制的に新投手へ交代
- 送りバント（球ごとカウント遷移、スリーバント失敗、2ストライクでヒッティング切替判断あり。打球方向抽選後に守備能力 vs 走力で結果決定: 成功 / バント安打 / バント失敗 / 併殺 / ポップアウト / 三振 / 四球）。3 塁ランナーがいる状況では発動しない（スクイズは別作戦扱いで未実装）。2 塁単独（1 塁空き）は 7 回以降+接戦のみ発動（早い回でヒットの可能性を捨ててアウトを増やすメリットが薄いため）。打順補正でクリーンアップはほぼバントしない
- 犠飛（外野フライ + 3 塁走者タッチアップ生還。打数に含めず、打点・出塁率分母には算入）
- 打点ルール（NPB 公式記録規則準拠）: エラー出塁で得点が入っても打者には打点をつけない。押し出し四球・押し出し死球・犠飛・通常打席は通常通り打点
- 個人「得点」集計（本塁を踏んだ選手を追跡し、ランキング・チーム成績に表示）
- フィールディングエラー内訳（捕球失策 / 送球失策 / クッション処理ミス / 中継返球ミス）
- オフシーズン進行 ON/OFF 設定（OFF で加齢・引退・新人加入をスキップ、選手をそのまま次シーズンへ）
- 延長戦（最大12回）・サヨナラ・引き分け
- シーズン試合数選択（30 / 90 / 150）+ 6チーム総当たり + 順位表 + 個人成績ランキング
- セーブ・ホールド・自責点（インヘリット走者対応）
- 複数シーズン化（加齢 + 年齢曲線 + 能力ポテンシャル + 引退・新人加入）
- 投手球速の NPB 水準化（平均 147 km/h、自然上限 158 km/h、編集 UI 上限 165 km/h）
